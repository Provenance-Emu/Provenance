### Added
- **Core Version Audit Script** — `Scripts/update_core_versions.py` scans each native core's source tree for version strings in `version.h`, `configure.ac`, `CMakeLists.txt`, `retro_get_system_info()` implementations, and similar files, then reports or updates `Core.plist` entries automatically.
- **Validate Core Versions workflow** — `.github/workflows/validate-core-versions.yml` runs the audit script on CI (weekly + manual trigger) and optionally opens a PR with plist updates when version drift is detected.

### Fixed
- **Core.plist versions corrected from source** — Five plists now reflect versions extracted directly from their submodule source: Genesis Plus GX (`v1.7.4`), Mupen64Plus-Next (`2.4`), PicoDrive (`2.03`), PokeMini (`v0.60`), TGBDual (`v0.8.3`). Normalised version strings reduce spurious save-state version-mismatch warnings.
