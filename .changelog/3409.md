### Added
- **Per-Game Save Export** — long-press a game → Export Saves creates a zip of battery saves and save states and opens the share sheet (iOS) or saves to Documents/Exports (tvOS).
- **SaveExporter service** — `PVLibrary.SaveExporter` supports both export and import of bundled save zips with MD5-validated manifests; import UI will be wired in a follow-up.
