### Changed
- **ArtworkLoader: shared local file URL resolver** — Extracted the artwork-file URL resolution logic (prefer `originalArtworkFile.url`, fall back to `PVMediaCache` keyed by `trueArtworkURL`) from `SaveStateBrowserView` into `ArtworkLoader.resolveLocalArtworkFileURL(forGameId:)` with a process-wide memo cache. Call sites no longer need to manage per-view state dictionaries; `clearLocalURLCache()` / `clearLocalURLCache(forGameId:)` are provided for invalidation after re-import.
