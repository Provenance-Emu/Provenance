### Fixed
- **Keyboard/Mouse Overlay Pause** — Toggling the virtual keyboard or mouse overlay from the tile menu now dismisses the menu and resumes the game, so the overlay is immediately usable.

### Added
- **Shader Settings Tile** — PauseTileMenuView now shows a "Shader Settings" tile when the active screen filter has adjustable parameters, opening an inline parameter editor sheet.
- **Port Devices Tile** — PauseTileMenuView shows a "Port Devices" tile for cores that support per-port controller device type selection (e.g. Joypad vs Mouse for Mario Paint).
- **MIDI Device Tile** — PauseTileMenuView (iOS only, not tvOS or macCatalyst) shows a "MIDI Device" tile for cores that support MIDI input/output, with RX/TX activity indicators.
- **Skins Tile** — PauseTileMenuView (iOS) shows a "Skins" tile that opens the full skin picker at the SKINS tab of the classic menu.
- **Consistent Quit/Resume Position** — Quit and Save & Quit tiles are now positioned immediately after Resume in the tile menu, matching RetroMenuView's top-of-menu ordering.
