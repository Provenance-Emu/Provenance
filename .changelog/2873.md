### Added
- **Core Language Setting** — New "Core Language" setting under Core Options lets users choose the language used by emulator cores; defaults to the device locale so games load in the user's preferred language automatically.
- **Locale→RetroArch Mapping** — `CoreLocaleMapper` in `PVSupport` maps iOS locale codes to RetroArch `RETRO_LANGUAGE_*` integers, covering English, Japanese, French, German, Spanish, Italian, Portuguese, Dutch, Polish, Russian, Korean, Chinese (Simplified/Traditional), Arabic, and Greek.

### Changed
- **RetroArch `user_language`** — `retroarch.cfg` is now stamped with the resolved `user_language` integer at every core launch (instead of the English default hardcoded in the bundled config), so locale changes take effect without resetting the config.
