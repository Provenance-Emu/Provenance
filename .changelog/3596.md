### Added
- **SaveState Intent** — Siri/Shortcuts intent to save the current game state to a specified slot.
- **LoadSaveState Intent** — Siri/Shortcuts intent to load a save state by slot or the most recent save.
- **TakeScreenshot Intent** — Siri/Shortcuts intent to capture a screenshot and return the image to Shortcuts for downstream actions.
- **AddCheat Intent** — Siri/Shortcuts intent to add a cheat code (GameShark, Game Genie, etc.) to the running game.
