### Added
- **mGBA RetroAchievements Integration** — Wires mGBA's native rcheevos support (`src/core/achievements.c`) to Provenance's achievement delegate system, exposing GBA EWRAM/IWRAM/SRAM and GB/GBC WRAM/VRAM memory regions, implementing hardcore mode save-state blocking, and enabling `achievementsActive` state tracking
- **Per-Game Mouse Input Override** — New "Mouse Input" picker in the Game Info screen lets users override automatic mouse detection for individual games (Auto / Always On / Always Off). Only shown for systems that support mouse input.
