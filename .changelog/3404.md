### Added
- **Dreamcast Mouse Support (Flycast)** — Flycast now routes mouse input to the Dreamcast Maple bus for games that use a mouse peripheral (Typing of the Dead, Planet Ring, Floigan Brothers, Industrial Spy, Dream Passport, and more)
- **Automatic Virtual Mouse Overlay** — The on-screen mouse overlay is shown only for known Dreamcast mouse titles; all other Dreamcast games continue using the standard controller
