issue: 3404
title: "feat(flycast): Implement Dreamcast Maple mouse device support"
type: feat
---

Flycast now routes mouse input to the Dreamcast Maple bus when a mouse-peripheral game is detected. The virtual mouse overlay is shown only for known mouse titles (Typing of the Dead, Planet Ring, Floigan Brothers, Industrial Spy, Dream Passport, and more). All other Dreamcast games continue using the standard controller.

Technical changes:
- `PVFlycastCoreBridge` now conforms to `MouseResponder`, wiring `mouseMoved`, `leftMouseDown/Up`, `rightMouseDown/Up` to the libretro mouse state setters.
- Added `configureDreamcastMousePort` which calls `retro_set_controller_port_device(0, RETRO_DEVICE_MOUSE)` lazily on first mouse input.
- Expanded `MouseGameRegistry` with additional Dreamcast mouse game title patterns.
- Added `dreamcast`/`flycast` to the RetroArch relative-mouse fallback lists so mouse deltas are routed correctly.
