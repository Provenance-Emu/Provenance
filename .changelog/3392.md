### Added
- **N64 Netplay via RetroArch** — `mupen64plus_next` and `parallel_n64` RetroArch cores support network play today via the existing `PVRetroArchCoreBridge+PVNetplayCapable` implementation (HAVE_NETPLAY already enabled). Use either RA N64 core to see "Network Play" in the pause menu.
- **MupenGameCore+PVNetplayCapable stub** — Native Mupen64Plus (`MupenGameCore`) now explicitly adopts `PVNetplayCapable` with `supportsNetplay = false`, documenting the pathway for future mupen64plus-netplay plugin integration (Option A rollback netplay).
