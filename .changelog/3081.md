### Added
- **Save State Version Mismatch Detection** — new `SaveStateVersionChecker` utility detects when a save state was created by a different emulator core version and presents an async "Load Anyway / Cancel" dialog before proceeding.
- **`createdWithCoreVersion` on `SaveStateInfoProvider`** — protocol now exposes the saved core version; a default `nil` implementation keeps existing conformers source-compatible.

### Fixed
- **Version mismatch alert hang** — `SaveStateVersionChecker.confirmLoad(on:)` now checks that the presenting view controller is in a window and not already presenting before showing the `UIAlertController`, preventing a continuation deadlock when the condition is not met.
- **Redundant `UIViewController` cast** — removed an always-true `self as? UIViewController` cast in `GameLaunchingViewController.openSaveState`; the extension constraint already guarantees `Self: UIViewController`.

### Changed
- **`PVEmulatorViewController+Saves`** — replaced silent "warn and proceed" version-mismatch behaviour with a proper confirmation dialog matching the `SceneCoordinator` path.
