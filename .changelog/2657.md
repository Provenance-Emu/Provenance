### Added
- **Focus Filter Intent** — `ProvenanceFocusFilterIntent` (`SetFocusFilterIntent`) lets users configure Provenance behaviour (suppress notifications) when a Gaming Focus is active via Settings → Focus → App Customization.
- **Continue Last Game Intent** — `ContinueMostRecentGameIntent` resumes the most recently played game; available as "Continue my last game on Provenance" in Siri and Shortcuts.
- **Search Library Intent** — `SearchLibraryIntent` returns filtered games by title and optional system; enables Shortcuts automations like "Find Mario games in Provenance".
