### Added
- **DualSense / DS4 Light Bar Theming** — `ControllerLightBarManager` applies a per-system color to the DualSense and DualShock 4 light bar (PSX = blue, SNES = purple, GBA = violet, N64 = blue, Sega = blue, Dreamcast = orange, Atari = gold, etc.). Per-system overrides are stored in `controllerLightBarSystemColors` UserDefaults. Light bar resets to default when emulation ends
- **DualSense Microphone Button → Audio Mute** — Pressing the DualSense mic button during gameplay toggles game audio on/off. The action is configurable in Settings → Controller → DualSense / DS4 Features (options: "Mute Audio", "None")
- **Controller Light Bar Settings** — New "DualSense / DS4 Features" section in Settings → Controller with a light bar toggle and mic button action picker
- **Share / Create Button Binding** — The DualSense Create button and DS4 Share button (`buttonOptions`) are now exposed as the `.share` `ButtonIdentifier` and dispatch through the button-remapping system, making them bindable to any in-game action
- **Touchpad Click Binding** — DS4 / DualSense touchpad click (`touchpadButton`) fires `handleSpecialButton(.touchpadButton)` and is therefore bindable via the controller remapping UI
- **`Defaults.Keys.controllerLightBarEnabled`** — Master toggle for controller light bar color output
- **`Defaults.Keys.controllerLightBarSystemColors`** — Per-system hex-string color override dictionary
- **`Defaults.Keys.dualSenseMicButtonAction`** — Configures what the DualSense mic button does (default: `"muteAudio"`)
- **`Notification.Name.PVControllerMicButtonToggleMute`** — Posted by `PVRemappableController` when the DualSense mic button is pressed; observed by `PVEmulatorViewController` to toggle `gameAudio` volume
