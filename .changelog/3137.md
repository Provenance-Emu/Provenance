### Added
- **PDF Size-Aware Rendering** — `UIImage(pdfData:preserveTransparency:)` now accepts an optional `size: CGSize?` parameter. When provided (and non-zero), the PDF is rendered at exactly that logical size using the current screen's retina scale, producing crisp HiDPI output. When omitted, the existing behaviour (native PDF size capped at 4096 px) is preserved. Call sites in `DeltaSkin.image(for:)` pass `rep.mappingSize` so skin images are rendered at the correct display resolution. Closes #3137.
- **Animated Button Sprites** — Skin buttons in `info.json` can now declare a `states` block (Manic EMU format) with `normal`, `pressed`, and `animated` image references. The new `DeltaSkinButtonStates`, `DeltaSkinButtonStateImage`, and `DeltaSkinButtonAnimated` model types are decoded from the skin ZIP and stored on `DeltaSkinButton`. `DeltaSkinView` loads and caches the per-button normal/pressed images, preferring the typed `states` field over the legacy raw-JSON `asset` dictionary. Part of #3133. Closes #3136.
