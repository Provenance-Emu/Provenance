### Added
- **PDF Size-Aware Rendering** — `UIImage(pdfData:preserveTransparency:)` now accepts an optional `size: CGSize?` parameter. When provided (and non-zero), the PDF is rendered at exactly that logical size using the current screen's retina scale, producing crisp HiDPI output. When omitted, the existing behaviour (native PDF size capped at 4096 physical pixels) is preserved. Call sites in `DeltaSkin.image(for:)` pass `rep.mappingSize` so skin images are rendered at the correct display resolution
- **Button State Image Support** — Skin buttons in `info.json` can now declare a `states` block (Manic EMU format) with `normal`, `pressed`, and `animated` image references. The new `DeltaSkinButtonStates`, `DeltaSkinButtonStateImage`, and `DeltaSkinButtonAnimated` model types are decoded from the skin ZIP and stored on `DeltaSkinButton`. `DeltaSkinView` loads and caches per-button normal/pressed images, preferring the typed `states` field over the legacy raw-JSON `asset` dictionary
