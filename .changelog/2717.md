### Added
- **Live Streaming via ReplayKit Broadcast Picker** — adds `PVBroadcastManager` (iOS 12+, tvOS 13+) wrapping `RPBroadcastPickerView` so users can start or stop a live broadcast to Twitch, YouTube, or any installed broadcast extension directly from the pause menu "GO LIVE" button. State is tracked in `EmulationUIState.isBroadcasting` and surfaced in the Capture section of the Retro Menu. Gated behind Provenance Plus where FreemiumKit is available.
