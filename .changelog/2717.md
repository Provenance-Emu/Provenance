### Added
- **Live Streaming via ReplayKit** — adds `PVBroadcastManager` (iOS 12+, tvOS 13+) wrapping `RPBroadcastActivityViewController` on both platforms so users can start or stop a live broadcast to Twitch, YouTube, or any installed broadcast extension directly from the pause menu "GO LIVE" button. Broadcast state is tracked in `PVBroadcastManager.isBroadcasting` (updated via `RPBroadcastControllerDelegate`) and surfaced in the Capture section of the Retro Menu. Gated behind Provenance Plus where FreemiumKit is available.
