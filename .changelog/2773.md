### Added
- **Controller Slot Preferences** — `PVControllerManager` now supports three slot-assignment modes per controller: `.auto` (unchanged first-available-slot behaviour), `.preferred(n)` (use slot *n* if free, else auto-assign), and `.always(n)` (always claim slot *n*, bumping the current occupant). Preferences persist across app launches and are applied on every connect/reconnect. A public `reapplyPreferences()` method re-applies all stored preferences after tvOS focus/wake events. Conflicts (two controllers both set to `.always(n)`) are handled gracefully — last-connected wins, warning logged. API: `slotMode(for:)`, `setSlotMode(_:for:)`, `clearSlotMode(for:)`, `preferredPlayer(for:)`, `setPreferredPlayer(_:for:)`, `reapplyPreferences()`.
