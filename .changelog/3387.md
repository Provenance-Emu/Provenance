### Added
- **mGBA Link Cable Netplay** — GBA, GB, and GBC games with link-cable multiplayer (Pokémon trading, Mario Kart link battle, etc.) can now be played across two Provenance instances on the same LAN Wi-Fi network. The host binds a TCP server socket; the client connects to it. A custom GBASIODriver exchanges SIO multi-player data each frame over TCP, mimicking a physical link cable.
