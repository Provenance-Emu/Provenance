### Added
- **License Generation Script** — `Scripts/generate_licenses.py` recursively scans all Core.plist files and generates `Scripts/licenses.json` and `LICENSES.md` with attribution data; use `--check` to validate completeness in CI
- **Shader Parameters for All Filters** — LCD, Mega Tron, ulTron, Game Boy, and VHS filters now expose fully editable parameters in the pause menu, matching the existing Simple CRT and Complex CRT controls.
- **Color Bar Filter Preview** — A SMPTE-style color-bar thumbnail with a filter-appropriate overlay (scanlines, grid, green tint, etc.) is shown above the parameter sliders so users can identify the effect at a glance.

### Fixed
- **LCD Blue-Line Artifacts** — Revised default subpixel `colorLow`/`colorHigh` values (0.6 / 0.95) to produce a more balanced RGB response and eliminate the blue-channel fringing visible at many screen resolutions.
- **LCD Harsh Grid at High DPI** — Reduced default `gridDensity` (0.8), `gridBrightness` (0.2), and `scanlineDepth` (0.15) so the LCD overlay looks natural on Retina displays without over-darkening the image.

### Changed
- **`hasCRTParameters` → `hasEditableParameters`** — `MetalFilterSelectionOption.hasEditableParameters` now returns `true` for every non-None filter; `hasCRTParameters` is kept as a deprecated alias for source compatibility.
- **Filter picker stays open** for any filter with editable parameters (previously only CRT filters).
