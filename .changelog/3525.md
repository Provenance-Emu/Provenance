### Added
- **Default DeltaSkin bundles for physical button cases** — Adds 7 pre-bundled DeltaSkin configurations for the GameSir Pocket Taco (NES, SNES, GBA, Genesis/MD) and Soolra Controller (NES, SNES, GBA). Skins use a transparent overlay to maximise the game screen when a physical controller is connected. Button coordinates are approximated and marked for real-device calibration
- **SVG controller artwork** — All default DeltaSkin bundles now include a `controller.svg` file showing a semi-transparent visual overlay of physical button positions, improving spatial orientation for users of grip controllers
- **SVG asset support in DeltaSkin loader** — `DeltaSkin.swift` now loads `.svg` files as resizable skin assets in addition to PDF and PNG, using a new lightweight `SVGRenderer`
- **`SVGRenderer`** — New `SVGRenderer.swift` implements `UIImage.init?(svgData:size:)` using `XMLParser` to rasterise a controller-artwork subset of SVG (rect, circle, ellipse, polygon, text, groups with translate transform) to a `UIImage` at the correct mapping size
- **New controller skin bundles** — 15 additional `.deltaskin` bundles:
  - `PocketTaco-GBC`, `PocketTaco-N64` — GameSir Pocket Taco GBC and N64 variants
  - `Soolra-GBC`, `Soolra-Genesis` — Soolra GBC and Genesis variants
  - `Backbone-NES/SNES/GBA/GBC/Genesis/N64` — Backbone One landscape clamshell skins
  - `RazerKishi-NES/SNES/GBA/GBC/Genesis/N64` — Razer Kishi v2 landscape clamshell skins
- **iPad support** — All portrait-grip skins (PocketTaco, Soolra) now include `ipad.standard` and `ipad.edgeToEdge` portrait representations in `info.json`
- **Skin generation script** — `Scripts/generate_default_skins.py` regenerates all 24 bundles from a single Python source of truth
