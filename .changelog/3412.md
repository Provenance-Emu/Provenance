### Added
- **Clip Capture** — Always-on ReplayKit clip buffer lets users retroactively save the last 30 seconds of gameplay. Available on iOS 15+ and tvOS 15+ (where ReplayKit clip buffering is supported). SAVE CLIP action is Provenance Plus-gated.

### Fixed
- **Clip temp file cleanup** — Temporary clip file is now removed after a successful Photos save on iOS, preventing accumulation of MP4 files in the system temp directory.
