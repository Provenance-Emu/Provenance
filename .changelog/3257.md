### Added
- **Animated Switch Button Support** — `DeltaSkinButton` now carries `selfRetracting` (momentary toggle) and `DeltaSkinButtonStates` gains `selected` + `switchAnimation` (spring-curve config) for Manic skin parity.
- **Extended Function Buttons** — `DeltaSkinInputHandler` now handles 40+ shortcut actions including `screenshot`, `restart`, `quit`, `saveStates`, `cheatCodes`, `skins`, `filters`, `speedMenu`, `toggleAnalog`, `swapDiscs`, `coreOptions`, `moreInfo`, and hold-style `slowMotion`.
- **Full APNG/GIF Background Animation** — `DeltaSkinAnimatedBackgroundView` uses `CGImageSource` to extract every frame from APNG/GIF files instead of showing only the first frame.
- **Platform Controller Grouping** — `DeltaSkinGameType` gains `skinLayoutGroup` and `isInSharedLayoutGroup` so MD/Sega CD/32X and Master System/Game Gear/SG-1000 (and GB/GBC, PCE/PCECD) share skin layouts automatically.
