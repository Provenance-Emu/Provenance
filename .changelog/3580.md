### Added
- **System directory mappings** — Added `systemDirectoryName` entries for MAME, NeoGeo, NeoGeoCD, CD-i, Macintosh, PC-98, MSX/MSX2, C64, and EP128. The thin libretro wrapper now returns `System/<name>/` for these systems instead of falling back to the BIOS directory.
- **Thin wrapper system directory validation** — PSP, N64 (mupen64plus-next), Dreamcast (Flycast jitless), and Atari ST are now documented as validated in the `systemDirectoryName` doc comment, with notes on Dolphin/PS2 JIT requirements.
