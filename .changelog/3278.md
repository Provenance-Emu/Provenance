### Added
- **In-Session Profile Swap** — "Controller Profile" tile in the tile-based pause menu lets players switch saved button-mapping profiles without leaving the game
- **Tap-to-Remap UX** — New `tapToRemapUI` feature flag (disabled by default) enables a "Press Mode" in Button Remapping settings where pressing a physical controller button assigns it as the remapping destination
- **`displayName` on `ButtonIdentifier`** — Human-readable labels for all button identifiers, used throughout remapping UI
