### Added
- **Drag & Drop Import** — ROM files and zip archives can be dragged directly into the game library from the Files app, AirDrop, and other file providers using `NSItemProvider`
- **ROM Drag Export** — Games in the library can now be dragged out to the Files app, AirDrop, or any file-compatible destination, vending the ROM file via `NSItemProvider`
- **Save State Drag Export** — Individual save state rows in the Save States browser can be dragged out as file URLs, enabling easy backup or transfer
- **Save Bundle Drop Import** — Save-export `.zip` bundles (produced by "Export Saves") can be dropped onto the Save States browser to automatically restore saves; the bundle's embedded manifest is read to match the game by MD5 hash
