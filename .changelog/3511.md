### Added
- **PVRcheevos SPM package** — New shared `PVRcheevos` / `CRcheevos` package that compiles the rcheevos C library (submodule at `PVRcheevos/rcheevos`); all native cores that need rc_client-based achievements can depend on this instead of bundling their own copy.
- **Mednafen Phase 2 — full rcheevos runtime integration** — `MednafenRcheevosObjC` target implementing the `rc_client_t` bridge for Mednafen: authenticates via stored RA credentials, calls `rc_client_begin_load_game`, drives `rc_client_do_frame` each frame, and routes achievement / leaderboard / challenge events to `achievementsDelegate` (PSX, NES/FDS, SNES via snes_faust, PCE/PCECD/SuperGrafx).
