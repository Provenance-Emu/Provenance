### Added
- **Save State Browser** — New full-page "Save States" tab in the main navigation shows all save states grouped by game title, with expand/collapse per game, screenshot thumbnails, core version info, and autosave filtering.
- **All Save States Browser** — "Show All" button in the Recent Saves section header opens a full-page browser that groups every save state by game with sorting (Most Recent, Oldest First, Game Name) and a favourites filter. Each game group shows all save types (auto, manual) as horizontally scrollable cards with context menus for Load, Manage, and Delete actions. Works on both iOS and tvOS.
