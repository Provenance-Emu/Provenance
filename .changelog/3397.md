### Added
- **Modern Web Server (Feature-Flagged)** — Introduces `PVWebServerManager`, a Swift actor that selects between the legacy GCDWebServer and the new Hummingbird 2-based `PVModernWebServer` at runtime via the `modernWebServer` feature flag. The new server delivers a dark-mode-aware drag-and-drop HTML file manager, async/await start/stop, WebDAV class-1 support, and proper multipart upload with the same `PVWebServer*Notification` constants. Enable in Settings › Advanced › Feature Flags (disabled by default). Part of Epic #2758.
- **`modernWebServer` Feature Flag** — Added to `PVFeatureFlags`/`features.json`; defaults to `false` so the legacy ObjC server remains active until the new implementation is fully validated.
