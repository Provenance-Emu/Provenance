### Fixed
- **RetroArch MIDI enabled by default** — `midi_input` and `midi_output` in the bundled `retroarch.cfg` now default to `"coremidi"` so DOSBox-Pure, Hatari, and other MIDI-capable RetroArch cores produce MIDI output on first launch without manual configuration

### Added
- **RetroArch MIDI toggle in pause menu** — The CORE tab in the pause/retro menu now shows an "Enable MIDI Driver" toggle for RetroArch-path cores running on MIDI-capable systems (DOS, Atari ST, MSX, etc.). The toggle persists across sessions and applies to `retroarch.cfg` on the next session start
