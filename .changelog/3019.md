### Fixed
- **JIT Indicator Tap Presentation** — replaced full-screen cover sheet with a compact `UIAlertController` alert showing a brief status message when the user taps the JIT HUD pill.
- **JIT Indicator Interaction** — enabled user interaction on the overlay so the pill button is actually tappable (previously blocked by `isUserInteractionEnabled = false`).

### Changed
- **JIT Core Detection** — `PVEmulatorViewController+JIT` now delegates to `PVEmulatorCore.jitRequirement` (the `PVJITRequirement` enum from #2793) for authoritative per-core JIT gating; `JITCoreCapability` is kept as a keyword-based fallback for UI contexts without a core object.
- **JIT Classification Corrections** — aligned `JITCoreCapability.isJITRequired` with the #2793 matrix: Dolphin (automatic-with-fallback) and PPSSPP (interpreter fallback) are now correctly classified as optional, not required.
