### Added
- **Companion DOS keyboard/mouse wiring** — Keyboard key presses and trackpad mouse events from the companion controller's `DOSKeyboardLayout` now flow through `CompanionInputRouter` to the DosBox emulator core via new `keyDown/keyUp/mouseMove/mouseButton` event cases.
- **`CompanionKeyboardBridge`** — New bridge class that converts `VirtualKeyboardDelegate` callbacks into `CompanionInputEvent` keyboard events, forwarded via the shared `CompanionInputRouter`.
- **`CompanionControllerCapable` protocol** — New `PVCoreBridge` protocol adopted by emulator cores that support direct keyboard and mouse input from a companion controller session.
- **`PVDosBoxCore+CompanionController`** — `PVDosBoxCore` now conforms to `CompanionControllerCapable`, routing companion keyboard events to its `KeyboardResponder` implementation and mouse events to its `MouseResponder` implementation.
