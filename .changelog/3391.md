### Added
- **Companion DOS keyboard wiring** — Keyboard key presses from the companion controller's `DOSKeyboardLayout` now flow through `CompanionInputRouter` to the DosBox emulator core via new `keyDown` and `keyUp` event cases
- **`CompanionKeyboardBridge`** — New bridge class that converts `VirtualKeyboardDelegate` callbacks into `CompanionInputEvent` keyboard events, forwarded via the shared `CompanionInputRouter`
- **`CompanionControllerCapable` protocol** — New `PVCoreBridge` protocol adopted by emulator cores that support direct keyboard and mouse input from a companion controller session
- **`PVDosBoxCore+CompanionController`** — `PVDosBoxCore` now conforms to `CompanionControllerCapable`, routing companion keyboard events to its `KeyboardResponder` implementation and mouse events to its `MouseResponder` implementation; mouse trackpad deltas accumulate into a normalized cursor position (0–1) before forwarding to the libretro mouse pipeline
- **DOS mouse trackpad routing** — `DOSKeyboardLayout` trackpad and mouse buttons emit `.mouseMove` and `.mouseButton` events that flow through `CompanionInputRouter.keyboardMouseEvents` to the DosBox core
