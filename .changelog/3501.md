### Added
- **Console Layout Variant Selector** — Choose the controller layout for systems with multiple peripherals: Genesis 3-Button vs 6-Button Pad, Wii Wiimote / Wiimote+Nunchuck / Classic Controller / Classic Controller Pro, Atari 5200 Joystick+Keypad vs Joystick Only, NES Standard vs Zapper. Selection persists per system in Settings → Systems.
