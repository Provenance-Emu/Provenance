### Added
- **N64 RetroAchievements (native Mupen64Plus)** — `MupenGameCore` now conforms to `CoreRetroAchievements`, exposing the N64 RDRAM memory region (8 MiB via `AudioInfo.RDRAM`) and lifecycle hooks so the rcheevos client can evaluate achievement conditions for N64 games played via the native Mupen64Plus backend.
