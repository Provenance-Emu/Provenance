### Fixed
- **Transfer Pak deadlock** — `dismissPreLaunchTransferPakSheet()` now resumes the launch continuation directly instead of relying on SwiftUI's `onDismiss`, which may not fire when the binding is set to nil programmatically on some iOS versions.
- **Transfer Pak crash in pause menu** — The game passed to `TransferPakConfigView` from `PauseTileMenuView` is now frozen before capture, preventing a Realm thread-violation crash when SwiftUI evaluates the sheet content.
- **Transfer Pak menu shown for incompatible N64 games** — The "Configure Transfer Pak" context menu item and pause-menu tile are now hidden for N64 games that are not known Transfer Pak titles. Games that already have Transfer Pak slots configured still show the tile.
