### Added
- **GameCube Z Button (Dolphin)** — R3 (right thumbstick press) now maps to the GameCube Z button when in GC mode, making it physically accessible on MFi controllers.
- **Saturn modifier combos (Mednafen, GCGamepad)** — On GC-style controllers, holding L1+R1 acts as a modifier so D-pad up/down trigger Saturn L/R triggers and modifier+A acts as an alternate Start input.
- **32X button mapping documented** — All 32X 6-button pad inputs (A/B/C/X/Y/Z + Mode + Start) are confirmed fully accessible via MFi+ controller standard mapping.
