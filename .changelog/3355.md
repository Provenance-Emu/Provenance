### Added
- **Hatari (Atari ST) MIDIResponder** — `PVHatariCore` now conforms to `MIDIResponder`, enabling the MIDI device picker UI for Atari ST games. Note On/Off, Control Change, Program Change, and Pitch Bend messages are encoded to raw MIDI bytes and injected into the libretro `retro_midi_interface` input ring buffer so the Hatari core receives them each frame
- **`pv_libretro_midi_inject_byte()`** — new C function in `PVThinLibretroFrontend.mm` that pushes a raw MIDI byte into the shared input ring buffer; thread-safe via `s_midiRingLock` serializing writes through `thin_midi_ring_write_byte`. Exposed via `PVLibRetroCoreBridge -injectMIDIByte:` for downstream libretro core bridges
