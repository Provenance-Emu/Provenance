### Added
- **StikDebug iOS 26 W×X script** — `Scripts/StikDebug/provenance.js` handles `BRK #0x69` sentinel from dynarec cores, authorises TXM execution pages, and creates RW alias via `vm_remap` for the dual-mapping W×X pattern required on iOS 26.
- **`DOLJitManager.isWXEnforced`** — static property that returns `true` on iOS 26+ where TXM enforces Write-XOR-Execute; dynarec cores can query this to select the correct JIT write path.

### Changed
- **JIT Onboarding alert** — updated wording to "Performance Mode" (Apple-safe framing) and added a "Try StikDebug" action alongside JITStreamer so users without a Mac have a direct path to acquire JIT.
