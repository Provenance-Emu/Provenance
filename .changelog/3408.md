### Added
- **Per-game Save Export** — long-press a game and choose "Export Saves" to package all save states and battery saves into a zip and share via the system share sheet; also accessible from the All Save States browser via a per-game export button
- **Drag Save States** — drag any save state card from the All Save States browser directly to Files.app or AirDrop
- **Drop Save Import** — drop a `.zip` export bundle or a `.sav` battery save file onto a game card to import it for that game
