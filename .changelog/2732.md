### Added
- **Per-Game Core Options Scope** — When Core Options is opened from the in-emulator pause menu, a "This Game / All Games" scope picker lets users set options that apply only to the current ROM, leaving global core defaults untouched.
- **Override Badges** — Option rows that have a per-game override show a small "Game Override" badge so the scope is immediately visible.
- **Reset Game Overrides** — A dedicated "Reset Game Overrides" button clears all per-game option overrides for the current ROM without affecting core-global settings.
