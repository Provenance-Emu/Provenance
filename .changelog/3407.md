### Added
- **ROM Drag Export** — Long-press a game tile in the library grid and drag it out to Files.app, AirDrop, or another app. Drag delivers the ROM file bytes via `NSItemProvider`. iOS/iPadOS only; tvOS is unaffected. Missing or iCloud-evicted ROMs produce a no-op drag instead of a crash. Supported in `ConsoleGamesView`, `HomeView` (Recently Played / Favorites / Most Played carousels), and `TVMediaGameTileView` (iOS landscape/controller UI).
