## MFi+ modifier swap-modes — Saturn, 32X, GameCube, Jaguar (#2817)

- **Saturn (Mednafen GCGamepad)**: Hold L1+R1 modifier — DPad Up → L trigger, DPad Down → R trigger, A → Start. Normal D-pad Up/Down and shoulder buttons suppressed while modifier active.
- **32X (PicoDrive GCGamepad)**: New GCGamepad section — A/B/C/X/Y/Z mapped to face+shoulder buttons; Hold L1+R1 combo adds Start (mod+A) and Mode (mod+B).
- **GameCube (Dolphin)**: Hold both triggers simultaneously in GC mode fires BUTTON_Z; trigger values suppressed during the combo to avoid accidental L/R presses.
- **Jaguar (RetroArch)**: Numpad buttons 1-4 now mapped to L3/R3/buttonOptions/buttonHome on the touch controller; 5-9 and 0 are no-ops pending additional core mappings.
