### Fixed
- **Hatari ACSI boot error** — `hatari_boot_hd` is now written to `Hatari/Hatari.opt` (the per-core options file RetroArch reads for `GET_VARIABLE`) with the valid value `"false"` instead of `"disabled"` in the appendconfig. Prevents the `--acsi ""` error that caused Hatari to fail on every launch
- **Hatari TOS byte repair** — added in-place repair of existing `system/tos.img` and `system/hatari/tos.img` files that carry corrupted address bytes from prior installs, so users no longer need to re-copy their BIOS to trigger the fix
