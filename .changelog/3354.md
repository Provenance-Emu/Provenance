### Added
- **MIDI device persistence** — selected MIDI source/destination survive app restarts via UserDefaults (`midiSourceUniqueID`, `midiDestinationUniqueID` keys).

### Fixed
- **PVLibRetroCore MIDI stub** — `RETRO_ENVIRONMENT_GET_MIDI_INTERFACE` now returns the CoreMIDI-backed interface instead of `false`, activating MIDI for all legacy-path libretro cores (DOSBox-Pure, Hatari, NP2Kai, ep128emu).
- **MIDI lifecycle** — `MIDIDeviceManager` is now connected to the active core on emulation start and disconnected on stop, preventing stale callbacks after a session ends.
