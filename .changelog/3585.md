### Added
- **Virtual Skin Controller (Companion App)** — Use the Provenance Companion app as a wireless gamepad: touch an on-screen controller layout and stream input to any DSU/CemuHook-compatible emulator (Cemu, Yuzu, Dolphin, Ryujinx) on the same network. Unlocked via a one-time StoreKit 2 IAP.
- **DSUSkinButtonMapper** — Maps Delta skin input IDs (`"a"`, `"l2"`, `"dpad_up"`, etc.) to DSU packet button bitmasks and analog byte values; covers all face/shoulder/dpad/meta buttons plus analog sticks with full alias support (Nintendo, PlayStation, and Xbox naming).
- **DSUSkinServer** — Actor-based DSU server that handles version/listPorts/padData client handshakes and pushes `controllerData` packets to subscribed clients at 60 Hz.
- **New IAP products** — `org.provenance-emu.companion.iap.virtual-controller` and `org.provenance-emu.companion.iap.cheat-library` added to the companion app's product catalogue.
