### Added
- **Mednafen Virtual Boy Palette Picker** — all 9 VB display modes (2D red/black, 2D white/black, 2D purple/black, and 6 3D anaglyph presets) are now selectable via the PalettePickerView tile in the pause menu
- **RetroArch Gambatte Palettes** — 15 GB/GBC palettes (DMG Green, GB Pocket, GB Light, GBC Blue, Brown, Dark Blue, Dark Brown, Dark Green, Grayscale, Green, Inverted, Orange, Pastel Mix, Red, Yellow) available when running GB/GBC ROMs via the gambatte-libretro core; palette is applied at runtime via the `gambatte_gb_internal_palette` core option
- **RetroArch mGBA Palettes** — 15 DMG-mode palettes available when running GB/GBC ROMs via the mGBA libretro core; applied via `mgba_gb_colors` core option
