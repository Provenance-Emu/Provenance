### Changed
- **Transfer Pak UI — Retrowave Theming** — Both `TransferPakConfigView` and `N64ControllerPakView` now use the Retrowave design system: dark grid background, neon-glow title, colour-coded port badges, and neon-border cards replace the plain `List` style.

### Added
- **Smart Game Suggestions** — The Transfer Pak ROM picker now highlights GB/GBC games that are specifically recommended for the N64 title being configured (e.g. Pokémon Red/Blue/Yellow for Pokémon Stadium) in a dedicated "Suggested" section.
- **"!" Badge for Unconfigured Slots** — The Transfer Pak pause-menu tile shows an exclamation badge when the game is a known Transfer Pak title but no slots are configured, nudging users without blocking launch.
- **Auto-Set Pak Type** — Selecting a GB game in `TransferPakConfigView` automatically switches that controller port to Transfer Pak mode via `N64PakStore`, eliminating the extra trip to Core Settings.
- **Skip-Prompt Memory** — Tapping "Skip & Launch" records a per-game flag so the pre-launch Transfer Pak prompt does not re-appear on every subsequent launch. "Clear All Slots" now resets this flag so the prompt resurfaces if the user wipes their config.
- **No-GB-Games Warning** — `TransferPakConfigView` detects an empty GB/GBC library and shows a clear "No Game Boy ROMs Found" call-to-action instead of an empty list.
- **N64ControllerPakView Retrowave** — Pak types are now colour-coded (Transfer Pak = hot pink, Memory = cyan, Rumble = orange, Smart = yellow) in an inline `Menu` picker replacing the navigation-link picker.
