### Added
- **MIDI Multi-Select Device Picker** — RetroArch quick settings now includes multi-select pickers for MIDI input sources and output destinations, with live RX/TX activity indicators. Multiple devices can be selected simultaneously; empty selection enables auto-detect (all sources) mode.
- **MIDI Category in Quick Settings** — New MIDI section in `RetroArchQuickSettingsView` exposes `midi_enable`, `midi_driver`, and `midi_volume` RetroArch config keys alongside the Provenance CoreMIDI device picker.

### Changed
- **`MIDIDeviceManager` multi-select API** — `selectedSourceID`/`selectedDestinationID` are now computed convenience accessors backed by `selectedSourceIDs: Set<MIDIUniqueID>` and `selectedDestinationIDs: Set<MIDIUniqueID>`. Existing single-select behaviour is preserved; `send()` now broadcasts to all selected destinations simultaneously.
