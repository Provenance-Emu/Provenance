### Added
- **Disc Serial Extractor Plugin Architecture** — Pluggable `DiscSerialExtractorPlugin` protocol in `PVHashing` with a `DiscSerialExtractorRegistry` singleton; built-in plugins for PSX/PS2 (ISO 9660 + SYSTEM.CNF), Sega Saturn/SegaCD/Dreamcast (IP.BIN header), GameCube/Wii (disc ID), and BIN+CUE (track resolver); import pipeline now attempts serial extraction before MD5 for CD-ROM titles, dramatically reducing lookup time for disc-based systems.

### Fixed
- **N64ROMNormalizer Linux build** — Added `#if canImport(CryptoKit)` guard so the module compiles on Linux using `swift-crypto` instead of the Apple-only CryptoKit framework.
