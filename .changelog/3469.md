### Added
- **Batch Artwork Source Filter** — Settings > Batch Artwork Matcher now shows per-source toggles (OpenVGDB, TheGamesDB, LibretroDB) so users can filter results by database
- **ArtworkMatchingService** — Centralised service wrapping `PVLookup` artwork search with `FuzzyGameMatcher` title normalisation and first-3-word fallback, replacing the duplicated `searchWithFallback()` helper

### Changed
- **Batch Artwork progress reporting** — The processing view now shows the title of the game currently being searched alongside the percentage bar
- **Retry failed artwork** — A "Retry (N)" button appears after a batch search completes, allowing failed lookups to be re-queued without restarting the full scan
