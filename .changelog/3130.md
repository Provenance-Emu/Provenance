## [#3130] Timing-based haptic patterns + per-system profiles

### Added
- `RumbleSystemProfile` in `PVPrimitives` — per-system haptic tuning profiles for N64 Rumble Pak, PSX DualShock, GBA cartridge motor, GameCube, Switch HD Rumble, and Xbox dual-motor
- `RumbleBurstClassifier` in `PVPrimitives` — pure stateless classifier that maps rumble burst timing to `RumblePattern` (shortTransient / mediumBurst / longSustained / rapidPulse)
- System profile wiring in `GCControllerHapticsManager` — tracks burst timing, counts pulses, applies profile-derived sharpness and motor scaling
- `setSystemProfile(_:)` and `setSystemProfile(forSystemIdentifier:)` public API on `GCControllerHapticsManager`
- `PVLibRetroRumbleHelper.setCurrentSystem(identifier:)` — convenience method to wire system profiles from libretro core load
- Unit tests for classifier and profile lookup in `PVCoreBridgeTests`

### Changed
- `PVLibRetroRumbleHelper.rumble()` now uses `duration: 10.0` (continuous until `stopRumble()`) instead of hardcoded 0.15s/0.08s
- `GCControllerHapticsManager.stopRumble()` now classifies burst duration and picks `UIImpactFeedbackGenerator` style (.heavy/.medium/.light/.rigid) based on pattern
- N64 rumble (`PVMupen64Plus-NXCore+Rumble`) updated to use N64-specific motor params (lowFreq: 1.0, highFreq: 0.2, duration: 10.0) and registers N64 profile on start
