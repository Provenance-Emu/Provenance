### Added
- **SNES Multitap (Mednafen)** — CRC32-based detection enables 5-player (and 8-player homebrew) multitap for snes_faust and bsnes modules; game list mirrors snes9x
- **Saturn TeamTap (Mednafen)** — Serial-based detection enables up to 6-player TeamTap with priority system: game database → user force-override → controller count fallback; port2 routing and buffer clearing supported
- **Genesis/Mega Drive TeamPlayer** — ROM peripheral header detection automatically enables 4-player TeamPlayer for Mega Drive games that declare multitap support in the ROM header

### Changed
- **Saturn TeamTap game database** — Combined game lists from two independent sources into a single comprehensive 100+ entry database covering Bomberman, Virtua Fighter, Street Fighter, Daytona USA, and more
