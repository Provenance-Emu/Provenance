### Added
- **CoreOptionsScope** — New `CoreOptionsScope` enum (`.perCore` / `.perGame(md5:displayName:)`) to express which storage key tier is active.
- **Per-game CoreOptions scoping (API)** — `CoreOptionsViewModel` now accepts an optional `PVGame` context; all reads and writes are routed through the matching per-game key when a game is set. This wires up the underlying `storedValueForOption(_:andMD5:)` / `setValue(_:forOption:andMD5:)` infrastructure — UI call sites are a follow-up.
- **hasPerGameOverride** — `CoreOptionsViewModel.hasPerGameOverride(for:)` returns `true` when a per-game override key exists for the given option, enabling future UI badge support.
- **resetToDefault** — `CoreOptionsViewModel.resetToDefault(option:)` removes the per-game override in `.perGame` scope or writes the declared default in `.perCore` scope.
