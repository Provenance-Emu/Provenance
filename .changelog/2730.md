### Added
- **CoreOptionsScope** — New `CoreOptionsScope` enum (`.perCore` / `.perGame(md5:displayName:)`) to express which storage key tier is active.
- **Per-game CoreOptions scoping** — `CoreOptionsViewModel` now accepts an optional `PVGame` context; all reads and writes are routed through the matching per-game key when a game is set.
- **hasPerGameOverride** — `CoreOptionsViewModel.hasPerGameOverride(for:)` lets the UI badge options that have been customised for the current game.
- **resetToDefault** — `CoreOptionsViewModel.resetToDefault(option:)` removes the per-game override in `.perGame` scope or writes the declared default in `.perCore` scope.
