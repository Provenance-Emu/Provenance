### Added
- **ProvenanceCompanion app target** — New iOS 16.0+ companion app shell (`org.provenance-emu.ProvenanceCompanion`) with placeholder TabView UI (Library, Peripherals, Settings tabs), shared App Group entitlement, and CloudKit capability pointing to the same container as the main app. This target is the container for the DriverKit system extension and serves as the App Store distribution vehicle for peripheral management. Includes AppStore and development entitlements, `ProvenanceCompanion.xcscheme`, and a `PBXFileSystemSynchronizedRootGroup`-based source layout.
