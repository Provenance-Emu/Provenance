### Added
- **Save Import Wizard** — multi-step retrowave-themed import wizard for save bundles (`.zip`), battery saves (`.sav`, `.srm`, `.ram`), and `.pvsave` files; accessible from Settings → Library → Import Saves or via any game's context menu → Import Save.
- **SaveImportMatchingService** — automatically matches a save bundle to a library game by MD5 manifest lookup (exact) or filename-heuristic Jaccard similarity (probable), with a manual game-picker fallback.
