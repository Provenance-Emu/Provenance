### Added
- **Transfer Pak support for Mupen64Plus-NX** — The Mupen64Plus-NX libretro core now implements `TransferPakSupport`, enabling GB/GBC cartridges to be mounted into N64 controller-port Transfer Pak slots (ports 0–3) for cross-game features (Pokémon Stadium, etc.)
- **`m64p_media_loader` registration** — Registers the Mupen64Plus media-loader API callbacks (`get_gb_cart_rom` / `get_gb_cart_ram`) so the emulator core can request GB cartridge ROM and RAM paths on demand during emulation
- **Transfer Pak controller pak mode** — Controller pak mode can now be set to `PLUGIN_TRANSFER_PAK` (4) per port; reverts to `PLUGIN_MEMPAK` (2) when a slot is cleared

### Changed
- **Mupen-NXOptions** — Transfer Pak (value 4) and Raw Data (value 5) are now selectable controller pak options in the N64 core settings
