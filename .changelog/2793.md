### Added
- **JIT Capability Matrix (`PVJITRequirement` + `PVJITRequirementRegistry`)** — each core declares its JIT requirement via a `PVJITRequirement` key in its own `Core.plist` (`required`, `optional`, or `notRequired`). `CoreLoader` automatically populates a thread-safe `PVJITRequirementRegistry` at startup — no hardcoded identifier list to maintain. The `jitRequirement(forCoreIdentifier:)` free function and `String.jitRequirement` extension delegate to this registry.
- **`PVJITRequirement` protocol-level property** — `open var jitRequirement: PVJITRequirement` on `PVEmulatorCore` (default: `.notSupported`) lets the app layer query any core's JIT requirement directly without a string lookup. Dolphin → `.automaticWithFallback`; melonDS, DeSmuME 2015, PCSX Rearmed, Mupen64Plus, PPSSPP → `.optional(fallback: "Interpreter")`; Azahar (Citra) and emuThree → `.requiredOrCrash`.
- **`PVJITRequirement` enum in `PVPrimitives`** — richer four-case enum with `.notSupported`, `.optional(fallback:)`, `.requiredOrCrash`, and `.automaticWithFallback`. Includes `isSafeWithoutJIT` and `hasJIT` helpers for the app layer.
