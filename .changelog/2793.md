### Added
- **JIT Capability Matrix (`PVJITRequirement`)** — new `PVCoreBridge` enum that classifies every emulator core as `notRequired`, `optional`, or `required` for JIT. Includes `PVCoreIdentifiers` constants for all known core IDs and a `jitRequirement(forCoreIdentifier:)` free function + `String.jitRequirement` extension for easy lookup. The JIT status indicator in `PVEmulatorViewController` now delegates to this matrix instead of a hardcoded keyword list.
