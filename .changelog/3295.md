### Added
- **RetroArch Transfer Pak (Mupen64Plus-NX)** — `PVThinLibretroCore` now conforms to `TransferPakSupport`, enabling the Transfer Pak slot-assignment UI and persistence layer for the thin libretro (RetroArch) emulation path. Setting a GB/GBC ROM on a controller port writes `mupen64plus-pak{N}=transfer` and the ROM path core option before the game loads.
