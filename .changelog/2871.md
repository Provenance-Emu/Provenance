### Added
- **Auto-translation script** — `Scripts/auto_translate.py` detects new/changed English strings and translates them to 11 languages (zh-Hans, ja, ko, es, pt-BR, de, fr, it, nl, ru, ar) using Claude Haiku, merging results in-place into existing `.lproj` files. Only translates delta keys for cost efficiency (<$0.01/run). The companion GitHub Actions workflow must be added manually by a maintainer (see PR #3506 for details).
