### Fixed
- **Skin picker race conditions** — hardened `DeltaSkinManager` against multiple concurrency hazards: added `dispatchPrecondition` guards so `scanForSkins` is always queue-confined; introduced a scan generation counter to prevent out-of-order stale MainActor updates from rapid successive scans; changed `skinsAreLoaded` to a `@Published` flag set on MainActor only after `loadedSkins` is populated (was incorrectly `true` before the MainActor update executed); `deleteSkin` now immediately removes the deleted skin from `loadedSkins` on MainActor in addition to `lastScannedSkins`, preventing SwiftUI from briefly showing a deleted skin; `loadSkinFromURL` now sets `hasScanned = true` so the cache fast-path works after a manual skin load.
