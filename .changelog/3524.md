### Changed
- **ArtworkMatchingService** — Extracted shared artwork-search fallback logic into a new `ArtworkMatchingService` actor (`PVLibrary`). Both the import pipeline (`ArtworkSearchQueue`) and the manual batch UI (`BatchArtworkMatchingView`) now delegate to this single service, eliminating duplicated code and ensuring consistent progressive fallback behaviour (exact title → cleaned title → filename → MD5 ROM lookup) across the app.
