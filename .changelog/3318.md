### Fixed
- **RetroArch core download pipeline** — `get-modules.sh` now exits non-zero when fewer than 80% of cores download successfully, preventing silent build failures where 0 cores load at runtime. Added zip magic-byte validation (rejects HTML 404 pages masquerading as zips) and 0-dylib guard that clears the download cache and fails the build phase.

### Changed
- **`get-modules.sh` shebang** — Changed from `#!/bin/sh` to `#!/bin/bash` to match bash-specific arithmetic syntax already used in the script (`(( ))` expansions).
- **`make_frameworks_retroarch.sh`** — Added explicit `exit 0` at end for clarity; script already exits non-zero on 0 frameworks from non-zero dylibs.

### Added
- **Script test suite** — `CoresRetro/RetroArch/scripts/tests/` with `test_get_modules.sh` and `test_make_frameworks.sh` covering: happy path, all-404 failure, partial failures, corrupt zip detection, pinned-date validation, pinned-date URL fallback, framework executable validation, and 80% threshold logic.
