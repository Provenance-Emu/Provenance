### Fixed
- **On-screen controller touch routing** — `QuickActionsContainerView` and `PassThroughView` now use explicit subview iteration in `hitTest` instead of `super.hitTest + self-equality check`. The container can never return `self`, so touches in dead-zone areas always fall through to the game-control views (JSDPad, JSButton) beneath the overlay. Fixes all plist-based UIKit controller buttons (d-pad, face buttons, shoulder buttons, start/select) being unresponsive after the keyboard/mouse/JIT overlay additions from PRs #3061 and related.
