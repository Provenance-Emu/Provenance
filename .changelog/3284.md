### Fixed
- **Hatari `--acsi ""` crash** — added explicit `[HardDisk]`, `[ACSI]`, `[SCSI]`, and `[IDE]` sections to the bundled `hatari.cfg` with all hard disk emulation disabled, preventing the hatari libretro core from passing an empty `--acsi ""` argument when no HD image is configured
- **Hatari debug logging** — added verbose before/after logging at every hatari option fix point (Options.swift, RetroArchUI.m, runloop.c, BIOS+AtariST.m) to aid diagnosis of future config issues
