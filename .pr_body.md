## PR body template

This file is intentionally checked in as a **generic template** for pull request descriptions.
It is **not** meant to describe any specific feature or issue, and should not be edited on a
per-PR basis.

CI workflows and/or contributors may copy this structure when drafting PR bodies:

### Summary

Briefly describe the purpose of the change in one or two sentences.

### Changes

- High-level bullet point of the main change.
- Another bullet describing a related change.
- Mention any important platform-specific behavior or guards, if applicable.

### Test plan

- [ ] List concrete steps to verify the change.
- [ ] Include both positive and negative cases where relevant.
- [ ] Note any platform-specific validation (iOS, tvOS, macOS, etc.).

### Notes

- Do not reference specific issue numbers or PRs in this template; add those in the actual PR.
- CI jobs that generate PR bodies should **not** commit the generated text back into the repo;
  they should treat this file as read-only structure guidance.

_If this file ever stops being used by tooling or documentation, it should be removed from the
repository to avoid clutter._
