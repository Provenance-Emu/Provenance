## Summary

Adds a dynamic camera corner picker to both pause menu variants — surfacing the setting inline so the user never has to leave gameplay to change which corner the face-cam appears in.

### Changes

- **RetroMenuView** (`stateMenuButtons` STATES tab) — `cameraPositionButton` appears directly below the Record button. It displays the current corner (`CAMERA: BOTTOM RIGHT`) and opens a confirmation dialog with all 4 options. Shown only when recording is available **and** the camera overlay is enabled in Settings.
- **PauseTileMenuViewModel** — appends a `cameraPosition` tile inside the recording block. The tile badge shows the active corner; long-press exposes a context menu with all 4 positions.
- **PauseTileMenuView** — handles `"cameraPosition"` tile taps (cycles to next corner) and long-press option selection (direct pick), both call `rebuildSections()` to keep the badge live.
- All three changes are wrapped in `#if os(iOS)` guards — no tvOS / macOS impact.

### Condition "when applicable"

The button/tile is shown only when **both** of these are true:
1. `PVRecordingManager.shared.isAvailable` — device supports screen recording
2. `Defaults[.recordingCameraEnabled]` — user has enabled the camera overlay in Recording Settings
